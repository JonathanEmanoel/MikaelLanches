# Mikael Lanches e Espetinhos

Cardapio digital simples, mobile-first, com produtos definidos no codigo, carrinho, checkout e geracao de pedido para WhatsApp.

## Rodar localmente

```bash
npm install
npm run dev
```

## Onde editar o cardapio

- Categorias: `src/data/categories.ts`
- Produtos, precos, imagens, adicionais e opcoes: `src/data/products.ts`
- WhatsApp e taxa de entrega: `src/constants/constants.ts`
